04 / READ WITH CARE

A project result, not a lending decision

The saved notebook does not export a trained model, so this page reports results and does not score new customers.

01

Low default recall. XGBoost recall is 0.3572 at the default threshold. Accuracy alone hides missed defaulters.

02

Test-set model selection. The notebook picks its top model by test ROC-AUC. Select on validation data, then reserve test data for final evaluation.

03

Preprocessing order. One-hot encoding happens before the split. Fit preprocessing within each training fold for a cleaner evaluation pipeline.

04

Different class handling. Random Forest uses balanced class weights; the other models do not, so settings differ.

05

Limited generalization. The Kaggle dataset describes Taiwan clients from 2005. Real use needs current representative data, fairness and privacy review, and human oversight.
